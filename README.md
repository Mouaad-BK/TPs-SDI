# Système Distribué Agentique — Travaux Pratiques

Ce dépôt regroupe les différents travaux pratiques réalisés dans le cadre du module **Système Distribué Agentique**.

Chaque TP est organisé dans un dossier séparé et contient :
- les fichiers et scripts développés pendant le TP ;
- un `README.md` présentant les objectifs, les concepts abordés et les principales étapes de réalisation (Rapport).
